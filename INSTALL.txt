LINK4BRICK v1.0.1 — TrimUI Brick Hammer / StockUI

INSTALL OR UPDATE VIA TERMINAL
Download LINK4BRICK-StockUI-v1.0.1.zip and install_link4brick.py into one folder.
Close the game, shut down the Brick, and connect its SD card to your computer.
Run (adjust the paths if needed):

  python3 ~/Downloads/install_link4brick.py --card /Volumes/128GBRICK

To validate without changing the card, add --check.
Python 3 is required. The installer checks every packaged app file and ARM64
binary, keeps your settings/enabled state and existing launcher backups, and
saves originals plus an installation.json undo journal on your computer.
It removes previous diagnostic helpers and the dedicated BrickTools cable
check entry. Other apps, ROMs, saves and emulator launchers are not modified
by the Terminal installation. Keep the reported backup folder.

If upgrading from Apps/AudioCast, first turn that old app OFF on the Brick.
Do not copy over active old launcher backups or remove them prematurely.
The package starts disabled; upgrades keep the current enabled state.

USE
Eject the card and reboot. Open Apps → LINK4BRICK, then set Enabled ON.
Connect the Brick and Push to the same Link-capable network.
Launch the ROM from Games → GBA. Choose Brick Out on Push once it appears.
The channel is recreated each game session; reselect it if necessary.

FMS GBA: select FMS GBA / 24 PPQ in LINK4BRICK, SYNC IN / GBA in FMS.
Brick START queues playback to the next four-beat Link “one.”
FMS Clock: match FMS SYNC IN / CLOCK and PPQ 1,2,3,4,6,8.
STEPPER: match its LINK IN mode and PPQ 4,6,12,24,48,96.
Set Link audio OFF for clock-only operation with the Brick speaker.
This uses a dedicated Link clock process, with no PCM capture FIFO or relay.
The emulator and local speaker conversion remain active.
Change settings only with the game closed. Audio buffer is fixed at 65 ms.
Use Push's incoming-audio synchronization/compensation for transport delay.
Game Boy clock and general multiplayer Game Link are not supported.

UNDO / REMOVE
Turn Enabled OFF before removing the app or editing its wrapped launchers.
OFF verifies and restores the original GBA launcher scripts. Changed launchers
or backups are preserved rather than silently overwritten.
To undo a Terminal update, use the installation.json path printed at install:

  python3 install_link4brick.py --card /Volumes/128GBRICK --undo /path/to/installation.json

Undo refuses changed managed files or damaged backups. Turn OFF first before
undoing a fresh install. Normal saves and private sync save states are preserved.

SAFETY AND LOGGING
No firmware, /etc/asound.conf, RetroArch binary or minarch changes.
ALSA/RetroArch routing uses process-private /tmp files; normal exits clean up.
The app creates no runtime logs. Older test logs remain untouched.
The icon shows enabled routing, not Link peer connectivity. StockUI may cache
icons; reopen Apps or reboot after installing new artwork.
